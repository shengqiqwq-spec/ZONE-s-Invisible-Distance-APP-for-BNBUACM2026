# 「看不见的距离」BNBU Programming Contest 参赛作品包

> 作品选题：The Invisible Distance（地图上的最短路径 ≠ 真实世界的最近路径）
> 赛道：BNBU Programming Contest · AI Track（预选：AI 评审打分 + 人工复查；决赛：观众投票）
> 创建时间：2026-10-11

---

## 一句话介绍

一个基于北师港浸大（BNBU）一期校园真实地理数据的 Web 可视化作品。通过对比「地图最短路径」和「考虑楼层高差、台阶、无障碍需求后的真实路径」，回答赛题核心问题：「什么时候，最短的路不是最近的路？」

---

## 快速开始

### 直接查看作品

用浏览器打开 **`作品/index.html`**（单文件，约 179KB，零依赖，不需要服务器）。

支持：Chrome / Edge / Safari / Firefox，以及手机浏览器。

### 作品核心交互

1. **中英文切换**：页头右上角 / 控制栏「中文 / EN」一键切换界面语言（地图标注、动态面板同步翻译）
2. **顶部视角切换**：普通行人 / 拖行李 / 轮椅——三种视角推荐不同路线
3. **楼层选择器**：选择图书馆或 V27 的当前楼层，查看出入口状态和路线提示
4. **地图工具栏**：勾选「路线」后显示两条真实 OSM 步道路径 + 方向直线 + 7 个可点击指引点
5. **无障碍视角**：一键高亮全部台阶，直观展示障碍分布
6. **移动端**：底部固定导航栏 + 手势缩放地图

## 作品技术栈

- **纯前端**：HTML5 + CSS3 + Vanilla JS（零框架、零依赖）
- **数据**：OpenStreetMap（Overpass API）+ 校方官方资料 + 用户现场核实
- **地图渲染**：Python 脚本将 OSM 经纬度投影为 SVG（Mercator 变体）
- **构建链**：Python 3.13 脚本自动组装单文件 HTML
- **响应式**：CSS Grid + Flexbox + 4 断点媒体查询
- **移动端**：CSS `touch-action` + JS 手势事件（单指拖拽、双指缩放）

## 2026-10-12 代码体检修复摘要

对 `作品/index.html` 做了一次逐行体检 + 无头浏览器回归测试，修掉 12 个问题，其中两个致命：

1. **切视角会清空地图 class** → 勾选「路线」或「无障碍视角」后，一按「拖行李 / 轮椅」就全部失效（视觉上路线直接消失）。
2. **「楼层高差」条形图把下坡 −1 层显示成 +1 层**，同一个面板里和表格自相矛盾。

其余包括：楼层高亮是死代码（缺 `#bld-library` / `#bld-v27`）、图书馆 tooltip 仍写 1 层、滚轮劫持页面滚动、
双击复位被捏合误触发、`touch-action` 与 JS 手势打架、中心湖不可见且中心岛被建筑盖住从未显示、
9 处空白楼栋标注、以及**缺失赛题硬性要求的「模拟数据标注」**。

完整清单、根因分析和 12 条回归测试结果见 **`文档/代码体检报告.html`**。
修改前的原始文件备份在 `_backup/`。

## 2026-10-13 更新：中英双语界面

作品页新增**中文 / EN 一键切换**（页头右上角与控制栏各一个切换器，两处状态同步）：

- 实现方式：`data-i18n` 标注 + 英文词典驱动的轻量 i18n 引擎，**零依赖**（仍是单文件）；
- 覆盖范围：静态文案（标题、命题 / 方法 / 结论、路线 C 说明、数据来源表、产品对比、页脚）＋ SVG 图面（楼栋名、道路、校门、湖心湖岸 / 中心岛、起终点、6 组指引浮层）＋ 动态面板（楼层状态、路线对比表与条形图、地图提示条、电梯时段、建筑 tooltip）；
- 中文原文在首次运行时快照保存，切回中文直接还原，**无需维护中文词典**；英文文案较长时自动放宽部分列宽，避免溢出。

对应回归护栏见 `脚本/verify_page.py` 的「P4 批次（中英文界面切换）」三条断言。
